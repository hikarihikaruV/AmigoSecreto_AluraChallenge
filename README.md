# Amigo Secreto -

Este proyecto implementa el clásico juego del **Amigo Secreto**, desarrollado como ejercicio de práctica en lógica de programación.  
La consigna consiste en permitir que los usuarios ingresen nombres de amigos, mostrarlos en una lista y, finalmente, sortear uno de forma aleatoria.

---

## Funcionalidades

- Agregar nombres mediante un campo de texto y un botón.
- Validar que el nombre no esté vacío.
- Mostrar los nombres agregados en una lista visible en la página.
- Sortear aleatoriamente un amigo secreto y mostrarlo en pantalla.

---

## Tecnologías utilizadas

- **HTML** → estructura de la aplicación.  
- **CSS** → estilos básicos.  
- **JavaScript** → lógica del programa (arrays, funciones, condicionales y bucles).
